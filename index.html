01 / LINUX

MENGENAL LINUX

Linux adalah sistem operasi yang banyak digunakan pada server, komputer, dan perangkat jaringan.

Pelajari pwd, ls, cd, mkdir, cp, dan cat untuk memahami terminal.

02 / ANDROID TERMINAL

BELAJAR TERMUX

Termux menyediakan lingkungan terminal Linux di Android tanpa harus melakukan root.

Gunakan untuk belajar Python, mengelola file latihan, dan memahami jaringan.

03 / PROTECTION

DASAR CYBER SECURITY

Upaya melindungi perangkat, akun, jaringan, dan data dari akses yang tidak sah.

Pelajari autentikasi, pembaruan perangkat lunak, dan pencadangan data.

04 / WEB

KEAMANAN WEBSITE

Website aman menggunakan HTTPS, validasi input, kata sandi kuat, dan pembaruan rutin.

Pengujian hanya pada website milik sendiri atau yang telah memberi izin.

05 / NETWORK

DASAR JARINGAN KOMPUTER

Pelajari IP, DNS, HTTP, HTTPS, router, dan komunikasi antarperangkat.

Gunakan ping, curl, dan traceroute pada jaringan yang diizinkan.
